Includes an **interactive web showcase and live smartphone emulator** with real-time lockscreen clock simulation.

## 🌟 Interactive Showcase Features

- **📱 Interactive 3D Phone Emulator**: Live-renders any wallpaper inside a realistic bezel with a real-time updating digital clock, battery/5G status icons, and lockscreen gesture hints.
- **⚡ Filter by Anime / Genre**: Instantly filter across *Romance & Slice of Life*, *Cyberpunk & Sci-Fi*, *Action & Shonen*, *Gaming & Fantasy*, and *Mecha*.
- **🔍 Instant Search**: Search by character name (*Chizuru*, *Komi*, *Lucy*, *Gojo*, *Makima*, *2B*), anime series, or review showcase.
- **🎲 Random Wallpaper Picker**: Click to pick a random wallpaper and test it on the phone screen.
- **💎 100% Original Resolution**: Zero fake upscaling, uncompressed source files directly from AlphaCoders, Wallhaven, and Pixiv artists.
- **🌙 Dark & Light Themes**: Cyberpunk dark mode by default with seamless light theme toggle.

## 🚀 Running the Showcase Locally

Clone the repository and launch any local web server:

```bash
git clone https://github.com/Arnav1771/tech-spurt-anime-wallpapers.git
cd tech-spurt-anime-wallpapers

# Using Python
python -m http.server 8080

# Or using Node / npx
npx serve .
```

Open `http://localhost:8080` in your web browser.
